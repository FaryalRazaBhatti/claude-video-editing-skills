# Other open-source video skills

Other people's skills that are worth a look. They are not part of this repository. Install them from
their own repos, which hold their licences and latest versions. Listed for reference only, with no
endorsement implied.

| Skill | Author | Licence | Notes |
| --- | --- | --- | --- |
| [video-editing-skill](https://github.com/6missedcalls/video-editing-skill) | 6missedcalls | MIT | Trims, jump cuts, caption styles. ffmpeg + Whisper |
| [vertical-video-editing-skills](https://github.com/nopefallacy/vertical-video-editing-skills) | nopefallacy | MIT | 9:16 shorts built with HyperFrames |
| [hyperframes](https://github.com/heygen-com/hyperframes) | HeyGen | Apache 2.0 | Video framework with several skills. Some features need API keys |
| [motion-graphics-skills](https://github.com/charlie947/motion-graphics-skills) | charlie947 | MIT | Launch-style motion graphics, built on HyperFrames |
| [video-use](https://github.com/browser-use/video-use) | Browser Use | MIT | Uses ElevenLabs for transcription (needs an API key) |
| [claude-remotion-skill](https://github.com/haidrrrry/claude-remotion-skill) | haidrrrry | MIT | Motion graphics with Remotion |
| [marketingskills](https://github.com/coreyhaines31/marketingskills) | Corey Haines | MIT | Marketing skill pack that includes a video planning skill |
| [video-edit-skill](https://github.com/tenfoldmarc/video-edit-skill) | tenfoldmarc | See repo | Talking-head reel editing |
